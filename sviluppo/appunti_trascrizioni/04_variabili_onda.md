# 04 — Lezione 5, 04/10/2021 (file 35): onde, variabili d'onda, problema agli autovalori 2D

Teoria (S "Wave solution of Euler equations"). Punti di metodo:

## Detto esplicitamente
- Visualizzazioni (es. CME solari) "da sola richiede un'interpretazione ... Senza un modello matematico non
  riusciamo a interpretarlo"; le equazioni "parlano come l'oracolo di Delfi" → l'interpretazione di immagini
  passa sempre dal modello.
- Entropia come s ~ p/ρ^γ, in forma differenziale **ds = dp − a² dρ** (nasconde le costanti; equivalente).
- Ribadisce isentropico (Ds/Dt=0 lungo traiettoria/linea di corrente) vs omoentropico (∇s=0).
- **Definizione di onda**: fenomeno che si propaga con velocità finita. Variabile d'onda = combinazione delle
  variabili primitive costante lungo una direzione nello spazio-tempo.
- **Monte / valle** (definizione del docente): monte = regione non ancora raggiunta dal fronte, valle = regione già
  investita. Lungo l'onda (surfista sulla cresta) non si vede variazione; l'intensità si misura
  **attraversando** il fronte.
- Formalismo: ξ_k = x·n_k − λ_k t, σ_k(ξ_k) variabile d'onda, R_k = dU/dσ_k autovettore destro (come l'onda agisce
  sullo stato: dU = R_k dσ_k), L_k sinistro (dσ_k = L_k dU), L_j R_k = δ_jk. Iperbolicità: autovalori reali +
  insieme completo di autovettori.
- Nota: 2D vs 3D differenza di dispersione geometrica (1/r vs 1/r²).
- Cita refusi nei testi (Courant–Friedrichs).
